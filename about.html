How ink works

ink is a real-time 2D fluid simulation rendered in WebGL. Pointer input writes velocity and dye into the simulation; a solver advances both every frame while dissipation fades them out. This page documents the pipeline, the inputs, and every setting.

Usage #

01

Paint

Drag anywhere on the canvas. Pointer velocity sets the force of each splat: slow drags produce wide ribbons, fast drags throw dye further.

02

Burst and pause

Burst (Space) injects eight random splats. Pause (P) halts the simulation loop; press again to resume.

03

Adjust

The Controls panel exposes ten settings (see Settings). Changes persist in this browser. Reset restores defaults.

Note Touch input works the same as cursor input — drag with one finger.

Simulation loop #

Each frame advances the simulation through the following passes, in order:

  1. Splat. Pointer deltas are written into the velocity and dye fields, scaled by brush force and radius.
  2. Vorticity. Curl is computed from the velocity field and fed back in, scaled by the Curl setting. This is what forms eddies.
  3. Pressure solve. Divergence is computed, then a Jacobi solver (Pressure steps iterations) derives the pressure field, which is subtracted from velocity to keep the flow divergence-free.
  4. Advect. Velocity and dye move along the velocity field. Velocity loss and density dissipation remove energy here.
  5. Display. Bloom, sunrays, and dithering composite over the dye field for output.

Reloading the page resets the simulation. Dial positions are the only persisted state.

Input #

Each pointer movement writes one splat: a velocity impulse along the direction of travel, plus dye at the pointer position. Radius and force come from the Brush settings. Stroke color is picked at random for every stroke.

Burst writes eight splats at random positions. Pause halts the loop without clearing state.

Dissipation #

Advection applies dissipation every frame, so dye and velocity decay toward zero. At defaults, a splash is mostly gone within a few seconds. Ink persistence sets density dissipation as 1 − v × 0.02, so higher values decay more slowly.

Dissipation is what clears the canvas for the next stroke.

Post-processing #

The solver output is matte. Light is added after the fact: Glow sets bloom intensity over bright dye, a sunrays pass adds directional shafts, and a dither texture (bloom-dither.png) breaks up gradient banding.

Setting Glow to 0 removes the bloom contribution.

Settings #

Ten settings in three groups. Reset restores defaults.

Brush

input

Radius
radius of each input splat (SPLAT_RADIUS)
Brush force
velocity impulse per splat (SPLAT_FORCE)
Brightness
dye intensity per splat (BRIGHTNESS)

Flow

fluid

Curl
vorticity confinement strength (CURL)
Velocity loss
velocity dissipation per frame (VELOCITY_DISSIPATION)
Ink persistence
inverse dye dissipation; higher lasts longer (DENSITY_DISSIPATION)
Ambient motion
background splat rate with no input (IDLE_INJECTION)

Simulation

solver

Pressure loss
pressure dissipation per solve (PRESSURE_DISSIPATION)
Pressure steps
Jacobi iterations; higher is smoother and more expensive (PRESSURE_ITERATIONS)
Glow
bloom intensity (BLOOM_INTENSITY)

Example Curl 6, Ink persistence at maximum, Ambient motion at 1 produces continuous flow with no input.

Note

On mobile, dye resolution is 512 (1024 on desktop) and pixel ratio is capped, trading detail for frame rate.

Runtime environment #

The simulation runs entirely in the browser on WebGL2, with a WebGL1 fallback. No painting data leaves the device. Dial positions persist in localStorage (ink:fluid-dials-v1); simulation state is never stored.

FAQ #

Is my painting saved?

No. Reloading resets the simulation. Only dial positions persist, in localStorage.

Why did the canvas go dark?

Dissipation clears dye over time. Drag anywhere or trigger Burst to add more.

Does it work on phones?

Yes, at reduced dye resolution with a capped pixel ratio.

Is anything uploaded?

No. There is no account, no server component, and no analytics on input.

What if WebGL is unavailable?

The canvas shows a notice and disables its controls. WebGL is usually blocked by browser or device settings — try another browser.
